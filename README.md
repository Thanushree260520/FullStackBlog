# FullStackBlog

A full stack blog application built with React, Node.js and Express.js. The application provides user authentication and complete blog post management with a clean and responsive dashboard.

## Features

- User registration
- User login
- JWT authentication
- Protected routes
- Create blog posts
- View all blog posts
- Edit your own posts
- Delete your own posts
- User profile display
- Post statistics
- Responsive dashboard
- Modern and clean user interface
- Logout functionality

## Technologies Used

### Frontend

- React
- Vite
- Axios
- CSS

### Backend

- Node.js
- Express.js
- JSON Web Token
- bcryptjs
- dotenv
- CORS
